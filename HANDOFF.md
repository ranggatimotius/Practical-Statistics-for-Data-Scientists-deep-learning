# Practical Statistics for Data Scientists — agent handoff

Updated 28 October 2026 (Asia/Jakarta). This is a handoff checkpoint, not approval to expand scope or deploy. Read repository instructions and inspect the current branch before making changes.

## Goal and actual scope
Deep Learning class learning repository covering ONLY chapters 1–4 of Bruce, Bruce and Gedeck's Practical Statistics for Data Scientists, second edition: exploratory analysis, sampling distributions, statistical experiments/significance testing, regression/prediction. The `deep-learning` suffix follows the assignment naming; these chapters are not neural-network implementations and the full book is not completed.

## Files and run
Read README for the four notebook links, concept map, dataset sources and limits. `Chapter_.../notebook.ipynb` contains original Indonesian explanations/code with saved outputs. Use the recommended Python 3.12 environment, install `requirements.txt`, and inspect `scripts/execute_notebooks.py` before running it. A Colab clone must include `data/`.

## Provenance and interpretation
Five small CSVs come from the authors' official companion repository; preserve their upstream GPL-3.0 license and attribution. Some sampling/bandit examples are synthetic and regression examples adapt scikit-learn data. Historical educational datasets must not become current medical/product claims. Observational associations are not automatically causal. Preserve these distinctions in summaries and new exercises.
